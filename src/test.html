UI Flow - Meeting Roles: Secretary / Host / Participant

Giao diện minh hoạ luồng cho từng vai trò trong 1 meeting (phân quyền theo meeting).

Secretary Role in this meeting

Upload Audio
Upload file → auto STT (DRAFT)
Transcript (DRAFT)
AI tạo transcript. Secretary có thể sửa: speaker tags, con số, tên...
Edit important spots only (spot-check) or full edit if needed
Summary
AI tóm tắt → Secretary chỉnh tay nếu cần
Actions
Khi gửi: summary status = REVIEWED → members can Confirm
After CONFIRMED
Tạo PDF → Ký số → Phát hành

Status Flow

DRAFT (AI) → REVIEWED (sent) → CONFIRMED (all/majority confirm) → SIGNED → PUBLISHED
Who can do what?
  • Secretary: upload, edit, send for review, create PDF, sign, publish
  • Host: review, final publish (approve release)
  • Participant: read transcript/summary, Confirm or Request changes
Shortcuts / Quality checks
Spot-check via summary, auto-detect low-confidence segments, highlight timestamps for manual review.

Participant / Host Role varies

View Summary (priority)
Fast read: participants usually check summary, not full transcript
View Transcript (detail)
Show speaker tags, timestamps; search within transcript
Actions
If Request changes → comment with timestamp → returns to Secretary
Host special
Host can approve final release after CONFIRMED
After PUBLISHED
All participants get email + PDF link. Minutes archived in Minutes DB.
Ghi chú: giao diện này mô tả luồng nghiệp vụ. Bạn có thể biến nó thành React component / Tailwind page để demo.
